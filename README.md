# Dashboard Canto do Sabiá

Prestação de contas do condomínio **Canto do Sabiá (132)**.

A fonte oficial de comportamento é [`DOCUMENTACAO-SISTEMA.md`](./DOCUMENTACAO-SISTEMA.md) (guia do dia a dia na §8).

```bash
npm install
npm run setup
npm run dev
```

App em `http://localhost:3002` (`npm run dev` usa a porta 3002 para não colidir com outros serviços na 3000). Testes de conciliação: `npm test`.
